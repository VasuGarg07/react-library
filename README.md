# React Library

A personal practice repo where I rebuild common React components and hooks from scratch to better understand how they work under the hood.

🔗 [Live demo](https://react-library-eta.vercel.app)

## What's here

A growing list of components and hooks I've been working through:

**Components** — Stepper, Nested Comments, Pagination, Progress Bar, Tree View, Carousel, Star Rating, Dialog, Virtualized List, Tabs, Typeahead Search, Accordion

**Hooks** — useOnlineStatus, useClickOutside, useDebounce, useLocalStorage, useTheme

## Stack

React, Vite, plain CSS. No UI libraries.

## Running locally

```bash
npm install
npm run dev
```
